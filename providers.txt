# │ Provider           │ Cache Type   │ Mechanism / Notes                             │
# │--------------------+--------------+-----------------------------------------------│
# │ wafer-serverless   │ pass-through │ Passes through underlying model cache pricing│
# │ zenmux             │ explicit/imp │ Ephemeral cache_control blocks (Anthropic)    │
# │ nebius             │ NONE         │ No documented caching support or pricing      │
# │ moonshot           │ implicit     │ Automatic system-managed prompt caching       │
# │ nvidia-nim         │ NONE (API)   │ Hosted API: no caching. Self-hosted: KV cache  │
# │                    │ + KV reuse   │  reuse via NIM_ENABLE_KV_CACHE_REUSE flag     │
# │ modal              │ NONE (API)   │ Hosted: no caching. Self-hosted: vLLM         │
# │                    │ + vLLM reuse │  --enable-prefix-caching available            │
# │ openrouter-presets │ pass-through │ Passes through upstream provider caching      │
# │ xiaomi-mimo        │ automatic    │ ~99% discount, GCache distributed, 93-95% hit │
# │ opencode-go      │ pass-through │ Passes through upstream model caching         │
# │ opencode-zen       │ pass-through │ Unified subscription pass-through caching     │
# │ zai                │ automatic    │ Implicit context caching, preserved thinking  │
# │ ollama             │ N/A          │ Local inference, no network caching           │
# │ pioneer            │ explicit/auto│ Claude requires cache_control; GPT is auto    │
#
# DETAILS:
# - DeepSeek models (all providers): Automatic KV caching. No request parameters
#   required. Prefix matching is handled entirely server-side. 64-token cache
#   units; practical minimum ~1,024 tokens. Cache-read ~10-50x cheaper than miss.
# - Anthropic models (via ZenMux/OpenCode Zen/OpenRouter): Explicit caching is
#   triggered by adding a "cache_control": {"type": "ephemeral"} parameter to
#   system prompt blocks, tool definitions, and historical conversation messages.
#   Local Router automatically injects these breakpoints for large prompts.
# - Xiaomi MiMo (all providers): Automatic server-side GCache distributed caching.
#   ~99% discount on hits. No request parameters required.
# - Z.ai GLM models: Automatic implicit context caching. Preserved Thinking mode
#   (clear_thinking:false) increases cache hit rates by keeping reasoning KV warm.
# - Moonshot Kimi K2 series: Automatic prefix caching, 50% discount. Must preserve
#   reasoning_content verbatim across turns. Optional prompt_cache_key for sticky routing.
