## Objective

Local Router must provide the infrastructure to run **typed decision models**
from every configured provider that serves them, so the engine's loopback
transport probe succeeds instead of reporting `Decisions Route: none
(chat-only entry)`.

## Trigger

## Contracts (verified live before coding)

- Canonical edge contract (TypeSafe System One, also OpenRouter Decisions):
  `{model, state, questions:{id:{type,instructions,criteria|options|levels}}}`
  → `{model, answers:{id:{type,noul|choice|score,...}}, usage}`.
- Engine probe (ainish-coder `src/rag/src/decision.rs`): `GET /v1/models` for any
  `jev` id, then `POST {base}/api/alpha/decisions` (then `/v1/decisions`,
  `/decisions`) with a minimal noul batch, **no auth header**, 1200 ms client
  timeout. Model posted is `typesafe/jev-1.14`.
- OpenRouter `POST /api/alpha/decisions` — live, 379–710 ms, returns dated model
  `typesafe/jev-1.14-20261014`.
- ZenMux `POST /api/v1/decisions` — route exists, validates strictly, but
  answers `404 model_not_supported` for `typesafe/jev-1.14` (model is catalogued,
  release pending). Request shape discovered by error iteration: `{model, input,
  questions:[{name, type:"choice"|"score", choices:[{value,description}] |
  levels:[{label,description}]}]}`; unknown keys rejected; no noul primitive;
  choices need ≥2.
