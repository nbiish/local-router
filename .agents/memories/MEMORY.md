## Decisions
- [2026-09-20] No-https-policy: tools refusing http://localhost base URLs are unsupported by policy; cross-boundary (Windows->WSL) access is a deployment concern solved by netsh portproxy or mirrored networking, NEVER a public tunnel (router has no inbound auth). *(source: operator directive 2026-09-19)*

- [2026-09-10] Graceful Cascade on Preflight Failures: Preflight failures (unknown model, no provider, no key/credits, allowlist reject) log skipped: true, stageAttempts: 0 and advance immediately to next fallback stage with zero retries; chain fails only on total exhaustion. *(source: memorix reasoning #5, engram obs:7)*

## Gotchas
- [2026-11-09] A verification harness that runs against the real `HOME` can rewrite production state: a scratch-port boot on the operator's home reordered `fallback-models.json`. Always give a verification run an isolated `HOME` and a scratch port, and back up before applying config. *(source: obs)*
- [2026-11-09] A 200 with `finish_reason:'length'` and empty `content` is a failed turn, not an answer: `openrouter-lfm-3-1.7b-free` with `reasoning_effort:'high'` billed 900 reasoning tokens and returned nothing while the fallback chain counted it a success. `classifyResponseContent` now treats no-content-no-tool-calls as `instant_error`; tool-call-only turns and reasoning-only text must still pass. *(source: obs)*
- [2026-11-08] A capability flag and the dial beneath it must be computed from the same facts. After the policy deploy the live router advertised 81 `reasoningEfforts` dials but only 40 `capabilities.reasoning:true` — a client reading the flag never renders the control, so the dial was unreachable. `/api/show`'s `capabilities` had the mirror bug (keyed off the dial, disagreeing with `/v1/models` for every cursor row). Both now answer "does this model reason" from one function. *(source: obs)*
- [2026-11-08] Only 3 of 1432 curated registry rows carry `supportsReasoning`, so a capability audit that trusts that flag will conclude most providers do not reason — including ones that do. Verify with a live call and billed `reasoning_tokens`, not with the stored boolean. *(source: obs)*
- [2026-11-08] A short prompt always reports `cached_tokens: 0` because it sits under every provider's minimum cacheable prefix (256 tokens Moonshot/Qwen, 1024 Anthropic/OpenAI). Any cache verification must use a prefix over that minimum or it proves nothing — `scripts/verify-live-cache.mjs` builds ~1300 tokens deliberately. *(source: obs)*
- [2026-11-08] Two wires silently dropped the caller's thinking level for months while every test stayed green: `/v1/messages` built its chat body from a fixed field list, and `translateResponsesRequestToChatBody` never read `body.reasoning`. The lesson is structural — a handler that assembles its own body bypasses the translator, so delivery has to be asserted at the route level, not only on the translation helpers. *(source: obs)*
- [2026-11-08] `injectPromptCaching` used to stamp breakpoints without counting the caller's own. Claude Code ships 4 markers and Anthropic caps at 4, so the extra markers earned a 400 instead of a cache hit. Any future marker injection must budget against the existing count. *(source: obs)*
- [2026-11-08] A policy row's `note` field is documentation, not evidence. `tests/provider-policy-docs.test.mjs` requires every caching row to cite an existing `docs/caching/*.txt` and every reasoning row to cite a measurement, a repo doc, a code path, or an explicit `[INFERENCE]` marker — so a claim without a source fails CI rather than reading as fact. *(source: obs)*
- [2026-09-23] A 2026-09-19 PQC-key diagnostic (`report.20260919*.json`) was committed with a plaintext OpenRouter API key and blocked every push (GH013) until purged whole-file from the unpushed history (isolated-clone filter-branch; remote never received it). Rule: diagnostic/export output with key material is contraband — redact at capture, purge temp artifacts at close; GitHub push protection now gates main. *(source: obs)*
- [2026-09-23] `local-router-ensure.timer` can double-spawn `build/index.js` when a manual `localrouter start|ensure` races its tick (two live processes; the state file may name the non-listener; only one binds 11434). Pause the timer (`systemctl --user stop local-router-ensure.timer`) inside the restart window. Also `localrouter status` immediately after start reports "No server detected" — that is the PQC pre-listen boot phase, not failure; probe `/api/version` instead. *(source: obs)*
- [2026-09-20] Router cross-store visibility: boot log prints `[PQC] sync: <dir>: N secret(s), M provider-mapped` per candidate store (ambient PQC_CONFIG_DIR, ~/.config/pqc-secrets, WSL /mnt/*/Users interop, LOCAL_ROUTER_PQC_EXTRA_DIRS `:`/`;`-separated). Zero-provider-keys warning fires when stores hold no provider-mapped keys. *(source: obs)*
- [2026-09-20] loadPqcSecrets spawns `uv run --script pqc_secrets.py export` synchronously BEFORE app.listen: cold uv cache + sandbox HOME (mktemp) stalls boot indefinitely — server never binds, node --test aborts at custom-providers.integration. Use LOCAL_ROUTER_SKIP_PQC_LOAD=true for local suite runs. *(source: obs)*
