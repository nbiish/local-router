# 2026-11-24 memory — Hermes & pi managed harnesses

- Hermes Agent stores config/profiles at `%LOCALAPPDATA%\hermes` on Windows (`HERMES_HOME` overrides on all platforms), not `~/.hermes`. `src/agent-hermes-config.ts` resolves both platforms and only auto-wires `model.provider`/`model.default` on `context-*` and `consolidate-*` profiles so unrelated operator profiles stay untouched.
- `pi` 1.5.0 resolves `local-router/fallback-models` via `providers["local-router"]` in `~/.pi/agent/models.json` (`PI_CODING_AGENT_DIR` overrides) with an explicit `models` entry for `local-router/fallback-models` and loopback `apiKey: "local-router"`.
- Integration tests spawning `build/index.js` must override `HERMES_HOME`, `CODEX_HOME`, `LOCALAPPDATA`, and `PI_CODING_AGENT_DIR` alongside `HOME`/`USERPROFILE` so host env vars never leak into test mutations.
